# Student Management System

Console-based Student Management System built in Java using OOP principles.

## Features
- Add Student
- Search Student (by roll number)
- Delete Student (by roll number)
- Show All Students
- Exception handling for invalid inputs (InputMismatchException)

## Tech / Concepts Used
- Java (Core)
- OOP (Classes, Objects, Encapsulation)
- ArrayList
- Exception Handling
- Code reusability (DRY principle)

## How to Run
1. Clone the repo
2. Open in IntelliJ (or any Java IDE)
3. Run `Main.java`

## What I Learned
- Structuring a project with separation of concerns (Main, Student, StudentService classes)
- Handling invalid user input gracefully
- Refactoring repeated code into a reusable method
